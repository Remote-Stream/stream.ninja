<h2>📌 درباره پروژه</h2>
<p>
## استریم نینجا Stream Ninja چیست؟ 🚀
یک ابزار استریم ویدیو همتا به همتا (Peer-to-Peer) است که برای اتصال دوربین از راه دور به OBS و سایر نرم‌افزارهای استودیویی طراحی شده و اکنون از طریق سایت remoteVm.site در دسترس است. ویژگی‌های اصلی:

🔒 ارتباط مستقیم ویدیو بین کاربران بدون نیاز به سرور مرکزی در اکثر موارد

⚡ کیفیت بسیار بالا با تأخیر بسیار پایین

🧑‍💼 کنترل پنل کارگردان با قابلیت گفت‌و‌گوی گروهی

📱 امکان استفاده از موبایل به عنوان وبکم بی‌سیم

🌐 پشتیبانی از WHIP/WHEP و امکان راه‌اندازی سرور اختصاصی SFU


  
است؛ ابزاری قدرتمند مبتنی بر فناوری WebRTC که امکان ارسال و دریافت ویدیوی زنده از طریق مرورگر را بدون نیاز به نصب نرم‌افزار و با تأخیر بسیار پایین فراهم می‌کند.
</p>

<ul>
  <li>✅ کاملاً <strong>رایگان</strong> و <strong>متن‌باز</strong></li>
  <li>✅ بدون نیاز به نصب برنامه</li>
  <li>✅ پشتیبانی از کیفیت FullHD و صدای استریو</li>
  <li>✅ مناسب برای OBS، vMix، XSplit و سایر نرم‌افزارهای استریم</li>
</ul>

<h2>🎯 کاربردها</h2>
<ul>
  <li>اتصال دوربین‌های راه‌دور به استودیوهای زنده (OBS، vMix و ...)</li>
  <li>تبدیل موبایل به وب‌کم بی‌سیم</li>
  <li>تولید محتوای زنده چندنفره از راه دور</li>
  <li>جلسات و مصاحبه‌های آنلاین با کیفیت حرفه‌ای</li>
</ul>
